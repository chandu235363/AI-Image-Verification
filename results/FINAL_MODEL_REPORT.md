# Final Model Report

## 1. Problem

Images may be authentic photographs, generated by AI systems, or altered through image manipulation. This project evaluates a classifier that assigns one of those three labels. It is an image verification aid, not proof of provenance or a guarantee that every edit will be identified.

## 2. Classes

- **Real** — authentic images from the selected COCO validation subset.
- **AI-Generated** — images from the selected GenImage AI subset.
- **Manipulated** — altered images from CASIA Tp.

## 3. Architecture

The production model is EfficientNet-B0 combined with handcrafted image features:

- FFT frequency statistics (5 features)
- Haar wavelet statistics (8 features)
- noise/residual statistics (4 features)
- standardized feature concatenation with EfficientNet-B0 deep features
- a three-class fused classifier

The checkpoint contains model weights, the class mapping, and the feature scaler statistics. No separate scaler file is required. Inference uses RGB conversion, square 224 × 224 LANCZOS resize, a JPEG quality 95 round trip, the EfficientNet image transform, the shared 17-feature extractor, the checkpoint scaler, and the same feature concatenation order used by training and evaluation.

## 4. Dataset

The dataset uses COCO `val2017` for Real, GenImage AI images for AI-Generated, and CASIA Tp for Manipulated. Preparation selected 2,000 images per class with fixed seed `20261002`, for 6,000 images total. The splits contain 4,198 training, 901 validation, and 901 test images; class counts differ by at most two images within each split.

Programmatic filename inspection found 5,123 readable CASIA Tp images in 16 parsed filename groups. Selection was deterministic and proportional to group availability, with a small minimum allocation where available, rather than taking the first sorted paths. Per-group splits ensure represented CASIA groups have test examples. The manifest records source path, hashes, split, family, and parsed group provenance. Full source and selected group counts are in `results/dataset_coverage_improved/DATASET_DISTRIBUTION_REPORT.md` and `dataset_distribution.json`.

## 5. Data Leakage Checks

The manifest was checked for cross-split duplicate source paths, source SHA-256 hashes, and prepared-image SHA-256 hashes. All three checks passed with **zero duplicates**. Test images were not used for candidate training or validation-based checkpoint selection. The three difficult CASIA diagnostic images were excluded from the dataset and used only for external inference diagnostics.

## 6. Baseline Model

The previous robustness-improved checkpoint was evaluated on the same 901-image held-out test split as the candidate.

| Metric | Previous model |
|---|---:|
| Accuracy | 90.90% |
| Macro F1 | 90.86% |
| Manipulated recall | 81.73% |

Its confusion matrix (actual rows, predicted columns; order Real, AI-Generated, Manipulated) was `[[281, 3, 16], [6, 292, 2], [48, 7, 246]]`.

## 7. Candidate Model

The final candidate improves CASIA coverage by sampling across the available Tp filename groups, including Tp_D, Tp_S, and their observed subgroups. Preparation creates separate train, validation, and test splits without the audited path or hash overlaps.

The candidate uses the existing EfficientNet-B0 fused architecture and was trained with transformation-aware training views. The original training views were retained; augmented views used crop, resize degradation, and JPEG compression. Validation selected the checkpoint. The test split was held out. Raw inference preprocessing was aligned with dataset preparation and the feature extraction used by training/evaluation.

**Production checkpoint:** `results/dataset_coverage_improved/efficientnet_fused_robust_balanced_best_model.pth`

The previous checkpoint is retained in the project workspace at `results/efficientnet_fused_robust_best_model.pth` as a backup; it is not required to run the final model.

## 8. Final Results

| Metric | Previous | Final |
|---|---:|---:|
| Accuracy | 90.90% | **91.56%** |
| Macro F1 | 90.86% | **91.59%** |
| Manipulated recall | 81.73% | **89.04%** |

The final confusion matrix (actual rows, predicted columns; order Real, AI-Generated, Manipulated) was `[[269, 2, 29], [8, 288, 4], [28, 5, 268]]`. On this test split, Manipulated → Real errors decreased from 48 to 28 and Manipulated → AI errors from 7 to 5. Real → Manipulated errors increased from 16 to 29, a relevant trade-off.

## 9. Robustness Results

The final model was evaluated on the same held-out test set using the project's deterministic crop, resize, JPEG, and combined transformations.

| Transformation | Final accuracy |
|---|---:|
| Original | 91.56% |
| Crop | 92.34% |
| Resize | 91.56% |
| JPEG Compression | 91.12% |
| Crop + Resize | 91.68% |
| Crop + Compression | 91.12% |
| Resize + Compression | 90.57% |
| Crop + Resize + Compression | 91.23% |

These are measurements for this held-out split and the specific transformation settings; they do not establish performance for other transformations or strengths. The full old-versus-new values, including manipulated recall, macro F1, and prediction consistency, are in `results/dataset_coverage_improved/robustness_comparison.csv`.

## 10. Unknown Image Validation

An unknown image was uploaded through the Flask upload route. Its SHA-256 did not occur in the candidate manifest. Flask returned **Real, 66.76% confidence**. It remained Real under the tested crop, resize, JPEG, and Crop + Resize + Compression variants. This is a single-image smoke test, not a performance estimate.

## 12. Limitations

Some manipulated images can still be misclassified, as the `cha10207` example demonstrates. The candidate also increased Real → Manipulated errors on the held-out set from 16 to 29, while improving manipulated recall. Some fine CASIA subgroups have small test counts, so their subgroup estimates are uncertain. Confidence values are model outputs and have not been established as calibrated probabilities. Results do not guarantee detection for unseen sources, manipulation types, or transformation settings.

## 13. Conclusion

On the measured held-out set, the candidate achieved higher overall accuracy, macro F1, and Manipulated recall than the previous model, and it had higher accuracy in each of the seven tested transformed conditions. It is configured as the production checkpoint, with the previous model retained as a backup. Its increased Real → Manipulated errors and the remaining CASIA false negative should be considered when interpreting predictions.
